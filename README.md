Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty
(`u-mfnakmal-dad-joke-showdown-1d2ce3e5`): one dad joke, at most 200
characters. A judge model reads entries two at a time and picks the one
that lands the bigger groan.

## The joke

> I asked my son for the ladder and he said, 'Dad, you're raising the bar.' I said, 'Son, that's the whole point.'

## How to run

Requires Node 22 or later (stdlib only, no dependencies):

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (no trailing newline).
For a local test, override the output directory:

```sh
OUTPUT_DIR=/tmp/dad-joke-out node main.ts
```
